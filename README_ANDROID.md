# نسخه اندروید جدول تناوبی ۱۱۸ عنصر

این پروژه نسخه اندرویدی برنامه جدول تناوبی است و با **Kivy + Buildozer** ساخته می‌شود. داده‌های ۱۱۸ عنصر، نام فارسی، عدد اتمی، عدد جرمی، دسته‌بندی، آرایش الکترونی و محاسبه آموزشی گروه از روی آرایش الکترونی در آن حفظ شده‌اند.

## تفاوت با نسخه ویندوز
در اندروید «Hover» واقعی مثل ماوس وجود ندارد. بنابراین با **لمس هر خانه** دو بخش اطلاعاتی نمایش داده می‌شود: کارت آبی اطلاعات عنصر و کارت بنفش محاسبه گروه.

## ساخت APK
بهتر است Buildozer را روی Linux یا WSL2 اجرا کنید. پس از نصب Python3 و Buildozer:

```bash
buildozer android debug
```

فایل APK معمولاً در پوشه `bin/` ساخته می‌شود. برای نسخه نهایی:

```bash
buildozer android release
```

برای اجرای آزمایشی روی گوشی با USB debugging نیز می‌توانید از ابزارهای ADB/Buildozer استفاده کنید.

## نکته
در محیط فعلی این گفتگو Android SDK/NDK و Buildozer نصب نیست و به اینترنت هم برای دریافت وابستگی‌های اندروید دسترسی نداریم؛ بنابراین APK کامپایل‌شده در این محیط تولید نشده و این پوشه پروژه آماده ساخت APK است.
